# Supporting analysis

These files supply the dependencies of the public topic results and the MHS application. They are part of the accepted proof, not disposable development files.

- [FunctionalAnalysis/](FunctionalAnalysis/README.md): weighted function spaces, tensors, integration, weak derivatives, extensions and estimates.
- [NonlinearAnalysis/](NonlinearAnalysis/README.md): nonlinear maps, quotient constructions and their differential estimates.
- [PhysicalAnalysis/](PhysicalAnalysis/README.md): the equation-specific linear inverse, regularity, tame estimates, original Newton construction and final integration.

The [module index](../MODULES.tsv) records the module names, source paths and hashes. The reader-facing starting points are the [topic guides](../README.md) and the root showcases.
